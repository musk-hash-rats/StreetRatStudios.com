# Street Rat Studios Website

Static one-page website for Street Rat Studios with privacy and security positioned as the primary trust signal.

## Local Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## Files

- `index.html` - page content and structure
- `styles.css` - responsive visual system
- `app.js` - animated canvas background and reveal interactions

## Deploy

Upload the three site files to the Hostinger public web root, usually `public_html/`.
